#02_Movement

In this, I worked with loops and arrays to create motion on the canvas. I did this with the random generation of different-sized circles, in random shades of blue to represent raindrops. Instead of using a text array, I displayed text in the setup, then, with the loop reset, generated a new text along with a reset of the circles on the screen. 
<br><br>
This took a good amount of trial and error, as the text array option was my initial idea. However, when it did work, it interfered with the circles and didn't adhere to the spacing I wanted it to have. Instead, the use of the loop to reset the text worked out, allowing a helpful refresh option for the viewer to more clearly see the message. It takes inspiration from a song and text from a video game, meant to invoke a curious, peaceful emotion and the visual of raindrops falling on the page.
