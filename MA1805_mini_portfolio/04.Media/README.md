#04_Media

This project used media and the ways it can be interacted with through p5.js. I decided to use image files to create an effect I wanted, and initially attempted to create an effect with a gif file. However, as there are multiple frames, it is not easily possible to find a way to filter a gif image, so I instead took two separate frames of the animation and began working on a different media effect. Based on an example on the p5.js website, this project allows you to draw over the image on the canvas, revealing another underneath that almost directly parallels the initial image. 
<br><br>
The main issue I ran into while working on this project was the file size-- the frames I downloaded were cut off when they were resized to window width and height, and had to match up to the exact proportions of the original frames in order to display properly. However, I was able to resolve this after most of the code was finished, and no code adjustments were needed other than to resize the canvas to 900x900px. Additionally, the online example turned out to be outdated, which caused me trouble until I found the updated code that allowed the program to run properly. 
<br><br>
The project's images are two frames of a gif animation I created separately and inserted into this project. The top frame uses brighter colors and has a more positive connotation, as everything seems to be the way it should, a simple pixel art piece. However, when allowed to draw over the canvas using a copy function to paste the second image on top of the first, a darker frame is revealed. It shows darker colors and the destruction of the vessels that appear in the initial frame, meant to invoke surprise, confusion, and concern. While simple, the copy function allows this project to be interactable and reveal two pieces of art through the viewer's exploration and curiosity.
