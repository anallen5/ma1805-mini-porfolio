#03_Multiples

On this project, I relied on variables to create animated text, utilizing an idea from the Movement project and coding a text array. With no other elements aside from the text, there was little interference. The text is a simple line of binary, split by the individual character, hiding a message in itself. The text is in shades of green, meant to look similar to a hacker screen seen in popular media. The text is designed to fill out the entire page, moving vertically and then horizontally across the page until the window width ends. It can then be reset with a mouse click, running the same text across the screen again. 
<br><br>
There were several drawbacks with this idea. Initially, the text was meant to be a much smoother scrolling motion from the top of the screen to the bottom, and with a better choice of text than 1s and 0s. However, after struggling to position the characters in a way that didn't overlaps too much, and allowing them to fill up the screen, I decided I liked how the text ended up moving, singularly vertical and horizontal across the page. There were some issues with the reset, as it would only reset when the text hadn't filled up the entire screen. I fixed this by adjusting how the text changed when it reached window height and width, so that when clicking, all variables would reset to 0 and repeat the cycle. This project idea, again, was inspired by the concept of hacker screens seen in older film and television, often misrepresented and portrayed in a way that is visually interesting and logically nonsensical. There is a message in the binary used for the text array, but it likely cannot be viewed on the page, and has to be seen separately by looking at the code I used.
